# A first-run account of NVIDIA NIM hosted endpoints

This is my experience visiting build.nvidia.com create an account, get an API key,
and query a NIM hosted endpoint to get a model response. This is my attempt to
understand the developer journey starting from built.nvidia.com to getting my
first model response using a NVIDIA NIM hosted endpoint.

## How long it took

I went from zero to a working API key in about **3 minutes**. The account creation,
sign-in, and phone verification all fit inside that window without much friction once
the right button was found.

It took another three minutes to create a script and get a first model response.
The longest wait in the entire session wasn't signup or key generation it was the
model's own first response, which took up to a couple of minutes to complete
