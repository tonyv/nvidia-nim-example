# NVIDIA NIM Example

Scripts for doing a simple query against a NVIDIA NIM hosted endpoint. This was an attempt to understand the developer journey for going from zero to first token by signing up for an account at build.nvidia.com

## Getting Started

1. Clone the repo

```
https://github.com/tonyv/nvidia-nim-example.git
```

2. Add your NVIDIA API key to .env. See example in `.env.example`

3. Try running `nim-example-nvidia.py` and `nim-example-oai.py`

4. Replace `MODEL` in either script with another model string in the model catalog at https://build.nvidia.com/
